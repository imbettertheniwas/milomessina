ONE-TIME BROWSER SETUP

Connect your FOMO session.

The helper works in Chrome or Edge. Your signed-in FOMO tab supplies clan names and counts; Eyes saves the results for everyone viewing this page.

Download browser helper
  1. Unzip the download. In Chrome, open chrome://extensions (Edge: edge://extensions), enable Developer mode, choose Load unpacked and select the unzipped folder containing manifest.json.
  2. Open fomo.family in that browser and sign in.
  3. Open FOMO Campus → Eyes from your extensions, enter your campus admin password and select Connect.

Keep the browser and FOMO tab open. Counts refresh every 5 minutes; new clan searches run hourly. Reconnect daily or after restarting the browser. Use Pause or Disconnect in the helper to stop.

FOMO passwords, session cookies, wallets and trades are never exported. If FOMO changes its API or blocks a request, the helper stops that run and retains the saved snapshot.
